# Portal Data (`src/portal/data`)

## Overview
Static seed datasets, initial mock records, and MNC audit question definitions for the PaintKing Portal.

## Interface
- `mncAuditQuestionsData.ts:AuditQuestionItem`, `MNC_AUDIT_SECTIONS`, `INITIAL_MNC_AUDIT_QUESTIONS`
